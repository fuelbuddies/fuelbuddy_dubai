# Fuelbuddy Dubai

Custom Frappe app for the Fuelbuddy UAE ERPNext instance.

## Features

- **Back-dated Delivery Note drain (v3.6)** — fast, identity-preserving
  pipeline for submitting large back-dated DN backlogs without per-submit
  lock contention. See [`docs/back_dated_dn_drain.md`](docs/back_dated_dn_drain.md)
  for the design rationale, operational guide, and audit checklist.
